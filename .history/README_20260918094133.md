# TinyLink API

A simple URL Shortener REST API built with Laravel. It allows users to create short URLs from long URLs, track click counts, and manage their own URLs securely using Laravel Sanctum.

## 🛠️ Tech Stack
- **Framework:** Laravel 11
- **Language:** PHP 8.3
- **Database:** MySQL
- **Authentication:** Laravel Sanctum
- **API Style:** RESTful JSON API

## 🚀 Project Setup

### Prerequisites
- PHP >= 8.2
- Composer
- MySQL / PostgreSQL
